# Golden Era v0.1.325 (Preview)

> **This is a preview build, not a finished release.** It still has issues. Most units have had an animation pass against the original HoMM3 animations, but some are still being polished, and some problems will only show up in play.

> **Want the newest fixes?** The [nightly build](https://github.com/leviritchie/Golden-Era/releases/tag/nightly) is rebuilt automatically as fixes land. It has more fixes than this release but is less validated: nightlies are not hand-tested. If a bug blocks you here, try the nightly.

## What changed since v0.1.324

### Gameplay Options on the main menu

A new **Gameplay Options** button on the main menu opens a window of optional game tweaks. Everything defaults to normal play, and your choices are saved in `BepInEx/config/GoldenEraGameplayOptions.json`.

- **Hero movement:** x1, x1.5, x2 or x3 adventure-map movement points (stacks with Logistics).
- **Experience gain:** x1, x1.5, x2 or x3. Heroes need less experience per level.
- **Neutral monster strength:** 50%, 75%, 100%, 150% or 200% size for wandering monsters and guards on generated maps.
- **One-time sites reset:** off, monthly or weekly. Sites you can only visit once, such as the Tree of Knowledge or Learning Stone, restock.
- **Monsters leave gold:** off, 10% or 25%. Beating neutral monsters pays that share of their recruit cost.

Movement and monster strength apply to new games; the others also apply to loaded games. Every side uses the options, AI included. They are for single player only. The options change game data in memory only: game files are not modified, and setting everything back to normal restores standard play.

### Faction laws

- **Rampart, Pegasus Screens** and **Bulwark and Factory, Battlefield Supremacy** now lengthen the **enemy** hero's spell cooldowns by 1 round, as their text says. Before, they lengthened your own hero's cooldowns.

### Compatibility with the current game patch

- Many mod hooks that were switched off on the current game patch, because the mod could not find the matching game code, have been re-mapped. They include quick combat, hiring from external dwellings, hero specialization icons and recruitment unit lists.

## Known issues

- The Gameplay Options window and the re-mapped hooks above have only had a short check in game so far. Please report anything that looks off.
- The Conflux town scene has not been rebuilt yet and still uses the older version.
- Town scenes can still show small streaks at some camera angles.
- Known issues from earlier releases still apply unless noted here. For example, the vampire line turns into mist while moving without a travelling effect, and a few neutral units are still in their animation pass.

Nightly builds are untested prereleases. If the problem persists on that build, please reply on the issue tracker.
